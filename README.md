# ChoreLight site (Bea7craft)

Host privacy + support for App Store Connect under **your** GitHub account.

## Your account

GitHub: **https://github.com/Bea7craft**

## Create repo + enable Pages

1. Sign in as **Bea7craft** → https://github.com/new  
2. Name: `chorelight-site` · **Public** · Create  
3. Upload `index.html`, `privacy-policy.html`, `support.html` from this folder  
4. **Settings → Pages** → Source: **Deploy from a branch** → `main` / `/ (root)` → **Save**
